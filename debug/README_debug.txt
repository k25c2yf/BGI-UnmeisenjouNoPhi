除錯測試包 phi_debug_patch（繁中 tc／簡中 sc，各兩個檔）

內容
- scrdrv._bp：只改 0x17A0 一個 byte（00→01），讓 scrdrv 載入 dbgmngr._bp。
- dbgmngr._bp：改了 work/flag 視窗的列表讀取。原本只顯示劇本用「登錄」指令加入監看清單
  （記憶體 0x3cc58+0x40e28，128 格）的項目，但 φ 正式版 scrsys 的登錄函式被常數 0 關掉了
  （scrsys 0x329D/0x32ED/0x3358/0x33C4/0x3430/0x349C 的「push 0; jz」），清單永遠是空的，
  所以只看得到 5 個標題。
  修改後每一區固定顯示編號 0～39：本地 work、全域 work、本地 flag、全域 flag、第二全域 flag。
  · 18 處「讀清單項目」（22 bytes）改成「編號 | 類型<<16」，其餘補成 +0，跳轉位址不變。
  · 5 處迴圈上限 0x80→0x28（0xF55、0x10FA、0x1299、0x14AE、0x16BA），避免超出 540px 視窗。
- 其他內容與 phi_sysprg_*_utf8.zip 中的同名檔相同（全檔 UTF-8）。

用法
1. 用這兩個檔替換 sysprg 裡的 scrdrv._bp、dbgmngr._bp，然後啟動遊戲。
2. 先點一下遊戲視窗，讓它取得焦點，再按 Home。按鍵只有遊戲視窗收得到，焦點在除錯視窗時按鍵無效。
3. 「Debug window」建立在遊戲畫面左上角（相對座標 0,0），「…work anf flag」在 x+546 處。
   如果主視窗沒看到，請拖開 work/flag 視窗，或把遊戲視窗移到別處再看。
4. 主視窗左上方 50px 是滑鼠座標列，滑鼠在遊戲內移動就會更新，可以用來判斷除錯程式是否還在執行。
5. Shift 手動刷新主視窗。work/flag 視窗會在劇本設定刷新旗標（0x0C738C→0x0C7390）時更新。

注意
- 顯示的是「編號」與「值」，沒有變數名稱（引擎本身就沒有名稱表）。
- 正式發布請改回 phi_sysprg_*_utf8.zip 裡的版本。
